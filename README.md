# 方仔摸鱼

一款竖屏休闲小游戏：按住屏幕让方仔摸鱼赚分，松开就假装在干活。老板会在办公室里走来走去、突然回头，回头前会有短暂提示（画面 + 可选提示音）。被抓到正在摸鱼就结束；如果一路躲到 18:00，就下班了。

纯静态 HTML / CSS / JS，无后端、无第三方库、无广告 SDK。资源路径全部是相对路径，放在 GitHub Pages 的 `/fangzai-moyu/` 子路径下也可以直接打开。

## 怎么玩

- **按住**屏幕（或鼠标）开始摸鱼，持续按住会叠连击倍率（最高 ×5）
- **松开**就回到认真干活，老板看着的时候请务必松开
- 老板回头前会闪「有人来了！」并响两声提示音，看准时机再松手（好险躲开还有加分）
- 一局大约 30–90 秒：难度会逐渐升高（预警更短、检查更勤）
- 到 18:00 还没被抓到，就算摸鱼成功、准时下班
- 最高分保存在浏览器 `localStorage`
- 「分享战绩」会把成绩复制到剪贴板（失败时走备用方案）

右上角「♪」可静音，设置会记住。

## 本地预览

在本目录或上一级目录启动静态服务即可：

```bash
# 在 games 目录启动时，用子路径访问，最接近 Pages 的用法
cd ..
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/fangzai-moyu/
```

或在本目录直接：

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

## 技术说明

- 触摸：`pointer` 事件按住 / 松开，并关掉滚动、缩放、长按菜单
- 音效：Web Audio 振荡器，不加载音频文件；需先有一次用户手势才会出声
- 适配：竖屏 360×640 画布按比例缩放，横屏窄高度时会提示把手机竖过来
